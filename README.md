# Figurinhas da Copa 2026

Sistema de gerenciamento de figurinhas da Copa do Mundo, da disciplina de
**Estrutura de Dados** (Fatec Rio Claro).

Permite colecionar, trocar e organizar figurinhas usando estruturas de dados
implementadas do zero: **lista encadeada** (álbum) e **fila FIFO** (repetidas e
histórico). Nenhuma estrutura pronta do Python (`list`, `deque`) é usada para
implementar essas estruturas.
